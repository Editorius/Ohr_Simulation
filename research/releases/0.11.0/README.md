# Historisches vollständiges Upload-Paket 0.11.0

SHA256.json beschreibt den damaligen lokalen Export einschließlich Projektunterlagen, nicht den laufenden Git-Stand. Der erste GitHub-Upload hat die Punktdateien .gitignore und .nojekyll nicht übernommen. Diese werden mit der Projektpflege ergänzt. Neue Hosting-Pakete werden ausschließlich über scripts/export_release.py erzeugt und erhalten ihre eigene SHA256.json innerhalb des Pakets.
